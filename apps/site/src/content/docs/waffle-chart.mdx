## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, WaffleChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<WaffleChart
  parts={/* … */}
  ariaLabel="Waffle Chart"
/>
</ChartTooltipPortal>
```

## Código de esta demo

<details>
<summary>Ver fuente (`src/demos/waffle-chart.tsx`)</summary>

```tsx
import type { WafflePart } from "@carlos-burelo/klin";
import { ChartTooltipPortal, WaffleChart } from "@carlos-burelo/klin";

const parts: WafflePart[] = [
  { label: "Nómina", value: 52 },
  { label: "Materiales", value: 18 },
  { label: "Servicios generales", value: 20 },
  { label: "Mantenimiento", value: 10 },
];

function format(value: number): string {
  return new Intl.NumberFormat("es-MX").format(Math.round(value));
}

export default function WaffleChartDemo() {
  return (
    <ChartTooltipPortal>
      <WaffleChart
        parts={parts}
        ariaLabel="Composición del gasto operativo en cien partes"
        format={format}
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
