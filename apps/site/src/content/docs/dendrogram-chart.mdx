## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, DendrogramChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<DendrogramChart
  root={/* … */}
  ariaLabel="Dendrogram Chart"
/>
</ChartTooltipPortal>
```

```tsx
import type { DendrogramNode } from "@carlos-burelo/klin";
import { ChartTooltipPortal, DendrogramChart } from "@carlos-burelo/klin";

const root: DendrogramNode = {
  label: "Sistema educativo",
  children: [
    {
      label: "Básica",
      children: [
        { label: "Preescolar" },
        { label: "Primaria" },
        { label: "Secundaria" },
      ],
    },
    {
      label: "Media superior",
      children: [{ label: "Bachillerato" }, { label: "Profesional técnico" }],
    },
    {
      label: "Superior",
      children: [
        { label: "Licenciatura" },
        { label: "Posgrado" },
        { label: "Normal" },
      ],
    },
  ],
};

export default function DendrogramChartDemo() {
  return (
    <ChartTooltipPortal>
      <DendrogramChart
        root={root}
        ariaLabel="Estructura del sistema educativo mexicano por nivel y modalidad: la educación básica reúne más modalidades y la media superior es la más compacta"
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `aria-label` (única fuente de nombre, sin `\<title\>`).
- Cada forma con hover lleva `data-chart-tip` para el portal rico (las demos lo envuelven por defecto).
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
