## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, NightingaleChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<NightingaleChart
  data={/* … */}
  ariaLabel="Nightingale Chart"
/>
</ChartTooltipPortal>
```

import type { NightingaleDatum } from "@carlos-burelo/klin";
import { ChartTooltipPortal, NightingaleChart } from "@carlos-burelo/klin";

const data: NightingaleDatum[] = [
  { label: "Ene", value: 8 },
  { label: "Feb", value: 10 },
  { label: "Mar", value: 18 },
  { label: "Abr", value: 45 },
  { label: "May", value: 110 },
  { label: "Jun", value: 210 },
  { label: "Jul", value: 230 },
  { label: "Ago", value: 220 },
  { label: "Sep", value: 190 },
  { label: "Oct", value: 80 },
  { label: "Nov", value: 20 },
  { label: "Dic", value: 8 },
];

export default function NightingaleChartDemo() {
  return (
    <ChartTooltipPortal>
      <NightingaleChart
        data={data}
        format={(v: number) => `${v} mm`}
        ariaLabel="Lluvia mensual en CDMX en milímetros: se concentra de junio a septiembre con pico en julio y estiaje en invierno"
      />
    </ChartTooltipPortal>
  );
}

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `aria-label` (única fuente de nombre, sin `\<title\>`).
- Cada forma con hover lleva `data-chart-tip` para el portal rico (las demos lo envuelven por defecto).
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
