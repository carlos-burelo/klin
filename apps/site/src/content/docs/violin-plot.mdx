## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, type ViolinGroup, ViolinPlot } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<type ViolinGroup
  groups={/* … */}
  ariaLabel="Violin Plot"
/>
</ChartTooltipPortal>
```

```tsx
/**
 * Demo Violines del site (no se publica en el bundle de la lib).
 */
import {
  ChartTooltipPortal,
  type ViolinGroup,
  ViolinPlot,
} from "@carlos-burelo/klin";

const groups: ViolinGroup[] = [
  { label: "Matutino", values: [8, 9, 9, 10, 8, 9, 7, 9, 10, 8] },
  { label: "Vespertino", values: [7, 8, 7, 8, 9, 7, 8, 6, 8, 7] },
  { label: "Nocturno", values: [6, 7, 8, 7, 6, 8, 7, 9, 6, 7] },
];

export default function ViolinPlotDemo() {
  return (
    <ChartTooltipPortal>
      <ViolinPlot
        ariaLabel="Distribución de calificaciones de matemáticas por turno, con la mediana más alta en el matutino"
        groups={groups}
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `aria-label` (única fuente de nombre, sin `\<title\>`).
- Cada forma con hover lleva `data-chart-tip` para el portal rico (las demos lo envuelven por defecto).
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
