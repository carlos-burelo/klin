## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, ErDiagram } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<ErDiagram
  entities={/* … */}
  relations={/* … */}
  ariaLabel="ER Diagram"
/>
</ChartTooltipPortal>
```

```tsx
/**
 * Demo Entidad-relación del site (no se publica en el bundle de la lib).
 */
import { ChartTooltipPortal, ErDiagram } from "@carlos-burelo/klin";

export default function ErDiagramDemo() {
  return (
    <ChartTooltipPortal>
      <ErDiagram
        ariaLabel="Diagrama entidad-relación de tienda"
        entities={[
          {
            id: "cliente",
            name: "Cliente",
            attributes: [
              { key: "PK", name: "id" },
              { name: "nombre" },
              { name: "correo" },
            ],
          },
          {
            id: "pedido",
            name: "Pedido",
            attributes: [
              { key: "PK", name: "id" },
              { key: "FK", name: "cliente_id" },
              { name: "fecha" },
            ],
          },
          {
            id: "producto",
            name: "Producto",
            attributes: [
              { key: "PK", name: "id" },
              { name: "nombre" },
              { name: "precio" },
            ],
          },
        ]}
        relations={[
          { from: "cliente", label: "1:N", to: "pedido" },
          { from: "pedido", label: "N:M", to: "producto" },
        ]}
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/guias/accesibilidad](/guias/accesibilidad).
