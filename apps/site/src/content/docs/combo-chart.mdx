## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, ComboChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<ComboChart
  data={/* … */}
  xKey={/* … */}
  bars={/* … */}
  lines={/* … */}
  ariaLabel="Combo Chart"
/>
</ChartTooltipPortal>
```

export default function ComboChartDemo() {
  return (
    <ChartTooltipPortal>
      <ComboChart
        ariaLabel="Gráfico combinado de ventas por canal y ticket medio por trimestre"
        data={[
          { trimestre: "T1", linea: 420, tienda: 380, ticket: 45 },
          { trimestre: "T2", linea: 510, tienda: 400, ticket: 52 },
          { trimestre: "T3", linea: 480, tienda: 450, ticket: 48 },

        ]}
        xKey="trimestre"
        bars={[
          { key: "linea", label: "En línea" },
          { key: "tienda", label: "Tienda" },
        ]}
        lines={[{ key: "ticket", label: "Ticket medio" }]}
        yAxisRight
      />
    </ChartTooltipPortal>
  );
}

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
