## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, ClassDiagram } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<ClassDiagram
  nodes={/* … */}
  edges={/* … */}
  ariaLabel="Class Diagram"
/>
</ChartTooltipPortal>
```

```tsx
/**
 * Demo Clases UML del site (no se publica en el bundle de la lib).
 */
import { ChartTooltipPortal, ClassDiagram } from "@carlos-burelo/klin";

export default function ClassDiagramDemo() {
  return (
    <ChartTooltipPortal>
      <ClassDiagram
        ariaLabel="Diagrama de clases del módulo de pedidos"
        nodes={[
          {
            id: "pedido",
            name: "Pedido",
            attributes: ["id: string", "total: number"],
            methods: ["confirmar()", "cancelar()"],
          },
          {
            id: "linea",
            name: "Línea",
            attributes: ["cantidad: number", "precio: number"],
            methods: ["subtotal()"],
          },
          {
            id: "cliente",
            name: "Cliente",
            attributes: ["nombre: string"],
            methods: ["comprar()"],
          },
        ]}
        edges={[
          {
            from: "linea",
            to: "pedido",
            kind: "composition",
            label: "contiene",
          },
          { from: "cliente", to: "pedido", kind: "association", label: "crea" },
        ]}
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/guias/accesibilidad](/guias/accesibilidad).
