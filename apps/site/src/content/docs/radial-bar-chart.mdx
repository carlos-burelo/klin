## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, RadialBarChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<RadialBarChart
  series={/* … */}
  ariaLabel="Radial Bar Chart"
/>
</ChartTooltipPortal>
```

```tsx
import type { RadialBarDatum } from "@carlos-burelo/klin";
import { ChartTooltipPortal, RadialBarChart } from "@carlos-burelo/klin";

const series: RadialBarDatum[] = [
  { label: "SRP", value: 91, max: 95 },
  { label: "Tétanos", value: 88, max: 95 },
  { label: "VPH", value: 82, max: 95 },
  { label: "Influenza", value: 78, max: 95 },
  { label: "COVID refuerzo", value: 64, max: 95 },
];

export default function RadialBarChartDemo() {
  return (
    <ChartTooltipPortal>
      <RadialBarChart
        series={series}
        formatValue={(v: number) => `${v}%`}
        ariaLabel="Cobertura de vacunación por biológico frente a la meta de 95%: ninguna la alcanza y el refuerzo COVID es el más rezagado"
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
