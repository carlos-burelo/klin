## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, WaterfallChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<WaterfallChart
  steps={/* … */}
  ariaLabel="Waterfall Chart"
/>
</ChartTooltipPortal>
```

## Código de esta demo

```tsx
import type { WaterfallStep } from "@carlos-burelo/klin";
import { ChartTooltipPortal, WaterfallChart } from "@carlos-burelo/klin";

const steps: WaterfallStep[] = [
  { label: "Saldo inicial", value: 120 },
  { label: "Recaudación", value: 85 },
  { label: "Nómina", value: -60 },
  { label: "Obra", value: -45 },
  { label: "Servicios", value: -20 },
];

function formatY(value: number): string {
  return new Intl.NumberFormat("es-MX", {
    style: "currency",
    currency: "MXN",
    maximumFractionDigits: 0,
  }).format(value);
}

export default function WaterfallChartDemo() {
  return (
    <ChartTooltipPortal>
      <WaterfallChart
        steps={steps}
        totalLabel="Saldo final"
        ariaLabel="Evolución del saldo presupuestal durante 2026"
        formatY={formatY}
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/guias/accesibilidad](/guias/accesibilidad).
