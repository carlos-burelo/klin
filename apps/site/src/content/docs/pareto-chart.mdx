## Uso

Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx
import { ChartTooltipPortal, ParetoChart } from "@carlos-burelo/klin";
import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<ParetoChart
  data={/* … */}
  xKey={/* … */}
  yKey={/* … */}
  ariaLabel="Pareto Chart"
/>
</ChartTooltipPortal>
```

import { ChartTooltipPortal, ParetoChart } from "@carlos-burelo/klin";

const data: Array<Record<string, string | number>> = [
  { causa: "Empaque dañado", devoluciones: 42 },
  { causa: "Talla equivocada", devoluciones: 35 },
  { causa: "Entrega tardía", devoluciones: 21 },
  { causa: "Color distinto", devoluciones: 12 },
  { causa: "Falla eléctrica", devoluciones: 8 },
  { causa: "Otra causa", devoluciones: 5 },
];

export default function ParetoChartDemo() {
  return (
    <ChartTooltipPortal>
      <ParetoChart
        data={data}
        xKey="causa"
        yKey="devoluciones"
        ariaLabel="Causas de devolución ordenadas con porcentaje acumulado"
      />
    </ChartTooltipPortal>
  );
}

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `\<title\>`.
- Cada forma lleva `\<title\>` nativo (tooltip sin JS) y `data-chart-tip` para el portal rico.
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/guias/accesibilidad](/guias/accesibilidad).
