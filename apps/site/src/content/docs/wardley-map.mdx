Ejemplo mínimo con las props requeridas. Copia, pega y cambia los datos:

```tsx

import "@carlos-burelo/klin/styles.css";

<ChartTooltipPortal>
<WardleyMap
  nodes={/* … */}
  edges={/* … */}
  ariaLabel="Wardley Map"
/>
</ChartTooltipPortal>
```

```tsx
import type { WardleyEdge, WardleyNode } from "@carlos-burelo/klin";
import { ChartTooltipPortal, WardleyMap } from "@carlos-burelo/klin";

const nodes: WardleyNode[] = [
  { id: "portal", label: "Portal ciudadano", x: 0.72, y: 0.92 },
  { id: "citas", label: "Motor de citas", x: 0.55, y: 0.68 },
  { id: "api", label: "API de trámites", x: 0.48, y: 0.5 },
  { id: "compute", label: "Cómputo", x: 0.82, y: 0.28 },
  { id: "datos", label: "Base de datos", x: 0.86, y: 0.14 },
];

const edges: WardleyEdge[] = [
  { from: "portal", to: "citas" },
  { from: "citas", to: "api" },
  { from: "api", to: "compute" },
  { from: "api", to: "datos" },
];

export default function WardleyMapDemo() {
  return (
    <ChartTooltipPortal>
      <WardleyMap
        nodes={nodes}
        edges={edges}
        ariaLabel="Mapa Wardley de la plataforma de trámites digitales"
      />
    </ChartTooltipPortal>
  );
}
```

## Accesibilidad

- Toda gráfica exige `ariaLabel` descriptivo; el SVG usa `role="img"` con `aria-label` (única fuente de nombre, sin `\<title\>`).
- Cada forma con hover lleva `data-chart-tip` para el portal rico (las demos lo envuelven por defecto).
- Sin datos se renderiza estado vacío homogéneo (`ChartEmpty`), nunca SVG roto.
- Detalle del contrato en [/docs/accesibilidad](/docs/accesibilidad).
